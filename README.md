🛒 E-Commerce Sales Intelligence System

📌 Project Overview

The E-Commerce Sales Intelligence System is a Python-based application designed to analyze e-commerce sales data and generate meaningful business insights.

It uses Python, Pandas, NumPy, and Matplotlib to process sales records, calculate revenue-related information, identify top-performing products, and visualize sales trends.

🎯 Project Objectives

- Analyze e-commerce sales data.
- Generate and maintain sales records.
- Calculate sales and revenue information.
- Identify top-performing products.
- Understand sales trends.
- Create visual representations of sales data.
- Support better business decision-making through data analysis.

🚀 Features

- 📄 CSV-based sales data generation.
- 📊 Sales data analysis.
- 💰 Sales and revenue calculations.
- 🏆 Top-performing product identification.
- 📈 Sales trend visualization.
- 🗂️ Sales record management.
- 🖥️ Menu-driven Python application.

⚙️ Installation and Setup

Prerequisites

- Python 3.10 or newer.
- pip package manager.

1. Clone the repository

git clone https://github.com/Jonnalasreeja21/E-Commerce-Sales-Intelligence-System.git

2. Navigate to the project folder

cd E-Commerce-Sales-Intelligence-System

3. Install dependencies

python -m pip install pandas numpy matplotlib

4. Run the application

python main.py
